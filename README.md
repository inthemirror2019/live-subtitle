# 译流 · 实时翻译字幕

把任何正在播放的声音，变成看得懂的中文字幕。

一个 Windows 桌面小程序：抓系统音频 → 实时语音识别 → 自动翻译 → 置顶悬浮字幕。看外语视频、直播、本地无字幕片源时，字幕直接浮在画面上。

> 工作名「译流」，取"译文如流"。当前是个人自用、开发中的状态，能用但不算精致。

---

## 它能做什么

| 场景 | 效果 |
|---|---|
| 看外语视频 / 直播 | 外文实时翻译成中文，浮在画面上 |
| 本地无字幕片源 | 任何能出声的程序都能覆盖 |
| 不想外放声音 | 配合虚拟声卡，静音也能出字幕 |

## 它不做

语音合成、配音、混音、音轨回贴。**只出字幕，不碰声音。**

---

## 工作原理

```
系统音频（WASAPI 回环，16kHz）
   ↓
流式识别 ── 在线：fun-asr-realtime（WebSocket）
         └ 本地：sherpa-onnx + X-ASR / Paraformer（纯 CPU，可离线）
   ↓
语言判定（中文转写 / 外语翻译）
   ↓
翻译（qwen-mt-flash / qwen-plus）
   ↓
置顶悬浮字幕（透明背景，滚动显示）
```

实测：识别首字 **0.6–0.8 秒**，端到端体感 **1.5–2 秒**（与 Windows 官方 Live Captions 同一水平，且多一步翻译）。

## 快速开始

### 环境要求

- Windows 10/11
- Python 3.14（本机 `C:\Python314`，需带 tkinter）

### 安装依赖

```bash
python -m pip install numpy soundcard aiohttp
```

### 配置 API Key

在项目目录创建 `config.json`（可参考 `config.example.json`）：

```json
{
  "keys": [{"name": "默认", "key": "sk-你的阿里百炼Key"}],
  "active": 0,
  "dst_lang": "zh"
}
```

或创建 `.env`：

```
DASHSCOPE_API_KEY=sk-你的阿里百炼Key
```

程序首次运行会从 `.env` 自动导入并保存。

### 启动

双击 `启动字幕助手.bat`，或：

```bash
python zhumu.py
```

## 使用说明

- **拖动**字幕条移动位置，拖**右下角**改大小（字号跟着变）
- **滚轮**微调字号
- **右键**菜单：设置 / 样式 / 倍速 / 移到底部居中 / 调整位置和大小 / 退出
- **双击**字幕条临时隐藏
- 空闲 5 秒自动隐藏字幕

### 本地识别（可选，省钱/可离线）

设置里「引擎」切到**本地**即可，不需要网络：

| 模型 | 体积 | 首字 | 特点 |
|---|---|---|---|
| **X-ASR 480 int8**（默认） | 163MB | 150ms | 中英混说更准，**自带标点** |
| Paraformer | 227MB | 139ms | 启动更快，中文纯语音准 |

- **本地只支持中英**，其他语言（日/韩/俄等）请用在线引擎
- 模型放 `D:/sherpa-models/`，可用「本地模型」下拉切换
- 首次加载约 2–5 秒（一次性）
- 装依赖建议用国内镜像：`pip install sherpa-onnx -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 延迟显示（可选）

勾选「显示延迟」后，会弹出**独立的小窗口**显示每句话的端到端耗时：

- 可**自由拖动**，位置会记住
- 5 套暗色主题可选（深灰/深蓝/纯黑/暖灰/米白）
- 在线引擎显示「从发声到上屏」，本地引擎为近似值
- 它和字幕窗是**两个完全独立的窗口**，互不影响

### 设置项

| 项 | 说明 |
|---|---|
| 多 API Key | 下拉切换，＋/－增删 |
| 音频源 | 选择回环设备（默认输出 / 虚拟声卡等） |
| 语言 | 源语言 → 目标语言 |
| 双语 | 是否显示原文 |
| 背景 | 透明 / 半透明底 |
| 倍速 | 1.0 完整 / 1.5 精简 / 2.0 压缩 |
| 引擎 | 在线 / 本地（本地仅中英） |
| 显示模式 | 按断句整段显示 / 打字机 |
| 显示延迟 | 独立小窗，可拖动、可选主题 |

## 已知限制

- **识别支持 7 种语言**：中 / 英 / 日 / 韩 / 俄 / 法 / 德（引擎实测，西语等会乱码）
- 翻译目标语言范围更广（10 种，翻译模型支持 92 种）
- 端到端 1.5–2 秒：受"等句子说完 + 翻译"限制，非识别拖累
- **本地引擎仅中英**，其他语言需在线引擎
- 腾讯视频等播放器可能压住字幕（独占全屏时无解）
- 音量过小可能漏翻（待修）
- 中英混杂句可能漏翻（语言判定待优化）
- 仅 Windows（依赖 WASAPI 回环）

详见 `需求清单-v0.9.md` 与 `现状总结与改进方向.md`。
